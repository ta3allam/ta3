# 🧪 QAI Automated E2E Testing Suite

This directory contains automated end-to-end (E2E) tests managed by **QAI**.

## Structure
- `tests/auth.spec.ts`: Login, session persistence, and role redirection (Student, Teacher, Admin).
- `tests/courses.spec.ts`: Course viewing, lecture playback, and RTL layout validation.
- `tests/assignments.spec.ts`: Homework upload dropzone and teacher grading flow.
